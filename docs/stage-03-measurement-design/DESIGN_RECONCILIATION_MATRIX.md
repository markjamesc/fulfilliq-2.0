2. **Volume:** post-exclusion `eligible_n < 30` → standard; ≥30 provisional floor.

5. **Coverage:** ≥95% provisional membership gate (A).

8. **SQL B:** raw B_orders+B_items+B_sellers; R(B) rebuilds all; A ↛ B.

10. **Dossier plan flag:** rejected as blocker; disclose non-RCT.
